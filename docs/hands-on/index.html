Claude Code를 GitHub Copilot 모델로 실행하기

로컬 브리지가 Claude Code의 요청을 Microsoft Copilot SDK로 전달합니다. 아래 두 구성 중 하나를 골라, 실제 터미널 화면 캡처와 녹화 영상을 보며 따라 해 보세요.

①

DirectLiteLLM 없음

권장

Claude Code→로컬 브리지→Copilot SDK

중간 게이트웨이 없이 로컬 브리지 하나면 됩니다. 설치 → 로그인 → 점검 → 실행 순서로 따라 하면 Claude Code 화면에서 Copilot 모델이 답합니다. 대부분은 이 구성으로 충분합니다.

  • 약 10분
  • macOS · Linux
  • Anthropic API 키 불필요
가이드 ① 열기 → 영상으로 먼저 보기
②

LiteLLM 경유게이트웨이 운영

선택

Claude Code→LiteLLM→로컬 브리지→Copilot SDK

가상 키와 요청 로그가 필요할 때 쓰는 구성입니다. 터미널 A에서 브리지와 LiteLLM을 띄우고, 터미널 B의 Claude Code가 LiteLLM을 거쳐 Copilot 모델로 답하게 만듭니다.

  • 약 20분 (LiteLLM 첫 설치 포함)
  • 터미널 2개
  • uv 필요
가이드 ② 열기 → 영상으로 먼저 보기

비공식 통합입니다. Claude Code에서 GitHub Copilot 모델을 쓰는 구성이며 Anthropic과 GitHub(Microsoft) 모두 이 조합을 지원하지 않습니다. 가이드의 화면과 영상은 실제로 실행해 캡처한 것입니다.
