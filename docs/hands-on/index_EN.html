Run Claude Code on GitHub Copilot models

A local bridge forwards Claude Code's requests to the Microsoft Copilot SDK. Pick one of the two setups below and follow along with real terminal screenshots and a recorded walkthrough.

①

DirectNo LiteLLM

Recommended

Claude Code→Local bridge→Copilot SDK

You only need one local bridge, with no gateway in between. Follow install → log in → check → run, and a Copilot model answers right inside Claude Code. This setup is enough for most people.

  • About 10 min
  • macOS · Linux
  • No Anthropic API key
Open guide ① → Watch the video first
②

Through LiteLLMGateway operations

Optional

Claude Code→LiteLLM→Local bridge→Copilot SDK

Use this setup when you want a LiteLLM gateway in front of the bridge, for example to get request logs. Start the bridge and LiteLLM in Terminal A; Claude Code in Terminal B then answers through LiteLLM with a Copilot model. It also shows how to add the bridge to a LiteLLM you already run.

  • About 20 min (incl. first LiteLLM install)
  • 2 terminals
  • Needs uv (to install a new LiteLLM)
Open guide ② → Watch the video first

Unofficial integration. This setup lets Claude Code use GitHub Copilot models; neither Anthropic nor GitHub (Microsoft) supports this combination. The screens and videos in the guides were captured from real runs.
